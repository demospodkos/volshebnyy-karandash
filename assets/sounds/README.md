# Звуки

Положи сюда сэмплы ксилофона:

- `xylo_c5.wav`
- `xylo_d5.wav`
- `xylo_e5.wav`
- `xylo_f5.wav`
- `xylo_g5.wav`

Можно сгенерировать на https://sfxr.me или взять royalty-free xylophone samples.
